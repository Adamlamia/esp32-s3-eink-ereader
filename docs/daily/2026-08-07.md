## Decisions Made

- **y = baseline everywhere:** all drawText/drawBookText y parameters are text baselines (~30px ascender above), not box tops. This ended the recurring Weather spacing failures.
- **fontSize removed:** FiraSans is the single UI font at one size; Georgia via drawBookText is the only real size lever. The no-op parameter was deleted so the trap cannot recur.
- **UI standard locked:** TITLE_Y=50, CONTENT_Y=130, ROW_GAP=8, FOOTER_Y=H-14, menu 74/230 — all in src/core/UiStyle.h.
- **Footer contract:** last-update info always bottom-right via drawFooter(); legend bottom-left.
- **Gesture deviations kept deliberately:** DevCompanion MediumHold=GitHub-view and Reader-Library LongHold=open-book — standardizing them would cost functionality.
- **Corrupt-file contract enforced:** truncated journal.json is rejected wholesale (returns 0), never half-parsed.

## Bugs Found & Fixed

1. **Baseline model misuse (Weather):** y treated as box-top caused clipping ("letters above the top border") and overlap; fixed in ea2ec2b.
2. **drawText fontSize was a silent no-op** — the root enabler of bug #1; parameter deleted in STD·R1.
3. **Launcher background tick caused unwanted calendar sync attempts** — removed (a15b593).
4. **writeVoiceQueue discarded its result:** const-ref signature meant the queue string was never updated — a latent device bug where /voice_queue.txt never changed after recording. Fixed in 9df3231.
5. **deserializeJournalCache off-by-ones:** all four JSON skip-offsets +1 too far ("entries":[ is 11 chars, not 12; title/ts/path keys likewise) — any real cache file would parse as 0 entries with truncated fields. Fixed in 9df3231.
6. **VoiceJournal geometry:** status line drawn at x=0/y=0 (off-screen baseline) — repaired in STD·R1.
